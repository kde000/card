# Визитка (пробная страница)

Мини-сайт-визитка для NFC-метки NTAG216. Клиент прикладывает телефон к брелоку —
открывается эта страница, где он может **сохранить контакт** или **вернуться позже**.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | сама страница |
| `style.css` | оформление |
| `app.js` | логика: сохранение контакта, QR, «поделиться» |
| `data.js` | **все ваши данные — править только здесь** |
| `me.vcf` | статичный файл контакта (резерв, если нужно дать прямую ссылку) |

## Как поменять данные

Откройте `data.js` и заполните поля: имя, должность, компания, телефон, email,
сайт, мессенджеры (MAX / Telegram / WhatsApp), адрес, заметку, акцентный цвет.

Файл `.vcf` и страница формируются из этих данных автоматически — вручную
`me.vcf` синхронизировать не нужно (он лежит только как готовый резерв).

### Фото

1. Положите картинку рядом с `index.html` (например `photo.jpg`) и укажите её
   в `data.js`: `photo: "photo.jpg"`. Можно и полный `https`-адрес.
2. Фото появится **на странице** (аватар) и **внутри контакта** — чтобы клиент
   увидел его в записной книжке.
3. Квадратный кадр, лицо в центре — смотрится лучше всего.
4. Перед вставкой в контакт картинка автоматически сжимается до 512 px,
   так что исходник может быть большим. Для быстрой загрузки страницы лучше
   держать файл до ~200 КБ.
5. Не нужно — поставьте `photo: ""`. Тогда на аватаре будут инициалы.

Отключить фото именно в контакте (оставив на странице): `photoInContact: false`.
Фото **не записывается в NFC-метку** — оно целиком живёт в интернете.

## Как посмотреть локально

Просто откройте `index.html` в браузере. Учтите: по адресу `file://` кнопка
«Сохранить контакт» работает, а вот QR и «поделиться ссылкой» покажут адрес
локального файла — они заработают после публикации в интернете.

## Как опубликовать (бесплатно)

Любой из вариантов, все дают ссылку вида `https://…`:

1. **GitHub Pages** — создайте репозиторий, залейте файлы, включите Pages
   (Settings → Pages → branch `main` / root). Адрес будет
   `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.
2. **Netlify Drop** — <https://app.netlify.com/drop>, перетащите папку целиком.
3. **Cloudflare Pages** — аналогично, через дашборд.

После публикации впишите адрес страницы в `data.js` в поле `pageUrl`
(или оставьте пустым — возьмётся текущий адрес открытия).

## Как это работает у клиента

- **Android:** включён NFC, телефон разблокирован → приложил к спинке → браузер открыл страницу.
- **iPhone XS/XR и новее:** приложил к верхнему торцу → появился баннер → тап → Safari.
- Приложение клиенту **не нужно**.

## Что записать в метку

Правило: в NTAG216 пишем **ссылку на эту страницу** (одну NDEF-запись `URI`).
Тогда содержимое можно менять на сайте, не перезаписывая метку.

```
NDEF record: URI
Value: https://ваш-домен/  (короткий!)
```

Советы:
- Ссылка должна быть **короткой** — её же вы нанесёте как QR на брелок.
- Ссылку ставьте **первой записью**, если добавите ещё что-то.
- После проверки на Android и iPhone метку можно **заблокировать** (Lock), чтобы не затёрли.

## Проверка перед печатью брелока

1. Опубликуйте страницу, скопируйте ссылку.
2. Запишите ссылку в метку (NFC Tools → Запись → URL).
3. Проверьте на **Android** и на **iPhone XS+**.
4. Проверьте кнопку «Сохранить контакт» на обоих.
5. Только после этого печатайте корпус и вклеивайте метку.
